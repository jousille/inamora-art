# INAMORA ART

The first editorial + immersive site prototype for the **PIXELISM** collection.

## Run locally

```bash
npm install
npm run dev
```

Build with `npm run build`; output is in `dist/`.

## Current state

- Responsive homepage, artwork catalog, filters for available and sold works, artwork details, About, Journal, enquiry selection, Contact and information placeholders.
- Demonstration canvas patterns are **not real artworks**.
- Artwork names, status, dates and descriptions are illustrative. Prices are not configured.
- No checkout, messaging, CMS or hosting deployment is connected.

## Editing content

Edit `src/data.js` for collection, artwork and Journal entries. Replace generated canvases with real artwork photography before launch. The first release keeps all content in source control; a CMS is a later enhancement.

## Branches

`main` remains untouched while the prototype is developed on `develop`.
